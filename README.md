# ✈️ British Airways Data Science Simulation

## 📌 Project Overview

This project was completed as part of the **British Airways Data Science Simulation**. It focuses on applying data science and machine learning techniques to solve real-world airline-related problems.

The project is divided into two tasks, covering data analysis, visualization, feature engineering, and machine learning.

## 📂 Project Tasks

### 🔹 Task 1 – Data Analysis

In Task 1, the dataset was explored and analyzed to understand the available data and identify important patterns.

Key steps included:

- Data loading and inspection
- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Data visualization
- Identifying useful patterns and insights

### 🔹 Task 2 – Machine Learning

Task 2 focuses on building and evaluating machine learning models.

Key steps included:

- Data preprocessing
- Feature selection and engineering
- Splitting data into training and testing sets
- Model training
- Model evaluation
- Comparing model performance
- Interpreting the results
